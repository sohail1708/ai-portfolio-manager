How the 11 agents pick stocks

Every weekday at 21:00 BST, this pipeline runs once per ticker. Each layer feeds the next; the Portfolio Manager at the end issues a single 5-tier rating.

1 Analysts · Parallel data gathering · 4 agents
📈 Market Analyst
Technical signals
Pulls OHLCV data, RSI, MACD, Bollinger Bands, moving averages. Identifies overbought/oversold and momentum.
gpt-5.4-mini · yfinance · stockstats
💬 Sentiment Analyst
Social sentiment
Reads Reddit/X chatter for the ticker. Flags retail euphoria, FUD waves, meme momentum.
gpt-5.4-mini · finnhub social
📰 News Analyst
Headlines + macro
Scrapes ticker-specific news + macro headlines (Fed, GDP, oil). Filters noise, surfaces catalysts.
gpt-5.4-mini · Google News
📊 Fundamentals Analyst
10-Q/K + ratios
Pulls latest filings, balance sheet, cash flow, P/E, FCF, insider trades. Assesses fundamentals.
gpt-5.4-mini · simfin/finnhub
2 Researchers · Adversarial debate · 2 agents
🐂 Bull Researcher
Argues to buy
Reads all 4 analyst reports. Builds the strongest possible bullish case. Counters bearish points. Cites past wins from memory.
gpt-5 · 1 debate round
🐻 Bear Researcher
Argues to sell
Reads same 4 reports. Builds the strongest possible bearish case. Highlights downside risks. Cites past losses from memory.
gpt-5 · 1 debate round
3 Research Manager · Synthesis · 1 agent
⚖️ Research Manager
Picks a side
Reads the bull/bear debate. Weighs the arguments. Produces a single investment plan: direction, conviction, key thesis points. Output goes to the Trader.
gpt-5
4 Trader · Position sizing + execution plan · 1 agent
🎯 Trader
Writes the proposal
Takes the investment plan. Writes a sell-side transaction proposal: BUY/HOLD/SELL, entry/exit levels, position size suggestion, stop loss, target.
gpt-5
5 Risk Team · Stress-test the trade · 3 agents
🚀 Risky Analyst
Push for bigger size
Argues the trade is under-sized or under-aggressive. Wants more conviction. Cites upside catalysts the others might miss.
gpt-5 · 1 round
🧊 Safe Analyst
Push for smaller size
Argues the trade is over-sized or too risky. Wants more caution. Cites downside risks, drawdown, tail events.
gpt-5 · 1 round
⚖️ Neutral Analyst
Adjudicate
Mediates between Risky and Safe. Surfaces blind spots. Pushes toward a balanced risk-adjusted view.
gpt-5 · 1 round
6 Portfolio Manager · Final rating · 1 agent
👔 Portfolio Manager
Issues the 5-tier call
Reads the full chain (analyst reports → debate → plan → trader proposal → risk debate). Issues exactly one rating: Buy / Add / Hold / Trim / Sell, with executive summary, price target, and stop loss. This is the output the executor acts on.
gpt-5
⬇ After all 9 tickers finish

Translator → Alpaca → Cash Park → EOD Snapshot

Each PM rating is mapped to a position size (Buy → 10% NAV · Add → 5% · Hold → no change · Trim → sell 50% · Sell → close). Orders are submitted to Alpaca paper. Idle cash above $500 is auto-parked in QQQ so the portfolio is never sitting in cash during a rally. An EOD snapshot logs NAV vs QQQ close to compute daily alpha.

🧠 Reflection memory loop

Each agent learns from past trades

5 trading days after a decision, the framework pulls the actual return vs QQQ and reflects on whether the call worked. Wins and losses are written to a per-agent memory file (Bull, Bear, Research Manager, Trader, Risk). Future runs read these memories to avoid repeating mistakes and double down on what worked. This is the "reinforcement" part — no gradients, just LLM context.

📝 Logged daily
Decision + full reasoning chain stored in SQLite + reflection log on disk.
⏱️ 5-day return check
Once outcome is known, ticker return + QQQ return are fetched and compared.
🔁 Fed back next run
Past wins/losses appear in each agent's prompt context the next day.

🛠️ Stack
  • LangGraph (agent orchestration)
  • Alpaca paper (executions)
  • yfinance + finnhub (data)
  • SQLite (state)

  • APScheduler on Fly.io (cron)
